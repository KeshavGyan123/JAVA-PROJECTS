# 🎓 Student Management System

A desktop-based Student Management System developed in **Java Swing**. The application allows users to perform complete CRUD (Create, Read, Update, Delete) operations on student records with file handling support for data persistence.

---

## ✨ Features

- 🔐 Login System
- ➕ Add Student
- 📋 View Students
- 🔍 Search Student
- ✏️ Update Student
- ❌ Delete Student
- 💾 Save Student Records
- 📂 Automatically Load Records
- 🖼 Java Swing Graphical User Interface (GUI)
